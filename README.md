# Документация проекта «Накорми зверей»

1. `CLAUDE.md` — правила работы агента и навигация по документации.
2. `PLAN.md` — короткий индекс задач и справочников.
3. `docs/tasks/Txx.md` — полная спецификация одной задачи; агенту загружать только нужный файл.
4. `docs/reference/R*.md` — справочники, разделённые по темам. Загружать только те, что названы в задаче.
5. `docs/OPEN_QUESTIONS.md` — реальные пробелы и противоречия, найденные при разборе исходников. Не разрешать их догадками.
6. `PROGRESS.md` — ведётся в самом проекте отдельно; не включён, поскольку пользователь его не предоставлял.
7. `docs/archive/` — точные исходники и устаревшие редакции для аудита. Не загружать в обычный контекст агента.

**Важно:** этот пакет содержит только реорганизацию документации. Игровые требования, числа и механики намеренно не «улучшались» и не исправлялись от себя. Полный исходный PLAN сохранён побайтно по тексту в архиве.
