# YG Skeleton: каркас игры для Яндекс Игр (Godot 4.7)

Что внутри:

| Файл | Зачем |
|---|---|
| `autoload/ya.gd` | Обёртка над SDK: инициализация, реклама (interstitial и rewarded), лидерборды, пауза и звук, LoadingAPI/GameplayAPI. Вне Яндекса работает как заглушка |
| `autoload/save.gd` | Сохранения: локально + облако Яндекса, побеждает более свежая копия |
| `autoload/loc.gd` | Локализация ru/en/tr, язык берётся из SDK |
| `web/shell.html` | HTML-шаблон: подключает `/sdk.js`, содержит JS-мост `YaBridge`, экран загрузки |
| `export_presets.cfg` | Веб-экспорт без потоков (не нужны COOP/COEP-заголовки), свой шаблон, `gl_compatibility` |
| `scenes/main.*` | Демо-сцена, чтобы проверить всё сразу. Заменяется вашей игрой |
| `tools/pack.py` | Пакует экспорт в zip с `index.html` в корне |
| `CLAUDE.md` | Универсальные правила для агента (Claude Code): что нельзя ломать, реклама, сохранения, вес, мобильность, определение готовности |
| `docs/PLAN.md` | План конкретной игры, заполняется под каждую игру |
| `tools/check.py` | Статическая проверка правил каркаса (без Godot): запрещённые вызовы, SDK не там, битые `res://`, бюджеты ассетов |
| `tools/build.py` | Одной командой: проверка, экспорт Web через Godot headless, упаковка в `game.zip` |
| `tools/new_game.py` | Создаёт новую игру из каркаса: `python tools/new_game.py "Название"` |

## Новая игра за минуту

1. `python tools/new_game.py "Название игры"` создаёт соседнюю папку с копией каркаса.
2. Открой её в Godot, заполни `docs/PLAN.md`, сделай `git init` и первый коммит.
3. Запусти Claude Code в этой папке: он сам прочитает `CLAUDE.md`. Задачи давай малыми шагами по плану.
4. Перед каждым коммитом `python tools/check.py`. Для релиза `python tools/build.py` (нужна переменная `GODOT_BIN` с путём к Godot либо `godot` в `PATH`).

Правки самого каркаса делай отдельными коммитами с префиксом `skeleton:`, чтобы переносить их в другие игры.

## Быстрый старт

1. Открой проект в Godot 4.7.x, поставь Web export templates (Editor > Manage Export Templates).
2. Запусти (F5). В редакторе SDK нет, поэтому работает заглушка: реклама имитируется, сохранения локальные.
3. Project > Export > Web > Export Project в `build/index.html`.
4. `python tools/pack.py` даёт `game.zip`, его заливаешь черновиком в консоль Яндекс Игр и проверяешь в реальном окружении.

## Как пользоваться в своей игре

```gdscript
await Ya.initialize()            # один раз на старте
await Save.load_all()            # подтянуть сохранения
Ya.loading_ready()               # игра загрузилась
Ya.gameplay_start()              # начало уровня (gameplay_stop() на паузе/выходе в меню)

Ya.show_interstitial()           # между уровнями; сам соблюдает интервал
Ya.show_rewarded(func(): Save.data["coins"] += 50; Save.save_data())

Save.data["best_score"] = 100
Save.save_data()                 # локально сразу, в облако с троттлингом
Ya.submit_score("main", 100)     # лидерборд надо создать в консоли

Loc.t("ключ")                    # тексты добавляй в словарь Loc.T
```

Во время рекламы дерево автоматически ставится на паузу и глушится звук. То же при уходе вкладки в фон и при паузе от платформы. Для этого узлы игры не должны иметь `process_mode = ALWAYS`, кроме тех, что нужны на паузе.

## Правила, чтобы билд был лёгким

- Только `gl_compatibility`, без 3D, без лишних шейдеров и частиц.
- Картинки: lossy WebP там, где можно, атласы вместо россыпи мелких файлов. Звук: OGG, музыка с низким битрейтом.
- Самый большой выигрыш даёт собственный Web export template с отключёнными модулями (3D, физика 3D, навигация и т.д.). Укажи его в `custom_template/release`. Это отдельная задача, можно сделать позже.
- Смотри вывод `pack.py`: что тяжелее всего, то и режь первым.

## Чек-лист перед модерацией

- Работает на телефоне в портрете/ландшафте (выбери ориентацию в консоли), нет горизонтального скролла.
- Есть языки ru/en (и tr, если аудитория есть).
- Реклама не показывается на старте и не чаще допустимого, rewarded даёт награду только в колбэке.
- Звук выключается при сворачивании и во время рекламы (уже сделано).
- Проверь актуальные требования консоли: они меняются, ориентируйся на их документацию.
