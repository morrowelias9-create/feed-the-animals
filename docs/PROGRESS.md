## Журнал

Агент дописывает сюда по 1-3 строки после каждого шага: что сделано, какие решения принял («решение: ...»), что осталось непроверенным. Новые записи внизу.

T01: сделаны game_config, zone_data, food_data, animal_data, upgrade_data, num_fmt и ключи Loc (ru/en); `check.py` и `check_loc.py` проходят без ошибок. Решение: game_config лежит в `scripts/data/` по структуре R5, временный `loc_keys_T01.txt` удалён.
Не проверено в движке: Godot на машине не найден, поэтому `NumFmt.format` и разбор скриптов запуском не подтверждены. Репозитория git не было — создан init-коммит каркаса.

T02: сделаны `throw_calc`, `spawn_roller`, `economy` — только статические функции без узлов. Решение: файлы перенесены из `scripts/data/` в `scripts/logic/` по структуре R5; формулы R3 сверены ручным расчётом (frog 1.0, lion 2800.0, sell 30.0, xp_needed(1) 14.07, rarity_share(0,4) 0.5).
Не проверено запуском: Godot не найден, поэтому типы `Array[float]` и разбор GDScript в движке не подтверждены; распределение 10000 бросков проверится в T04.

T03: добавлены `autoload/game.gd` по контракту R5, новые поля `Save.DEFAULTS`, автозагрузка `Game` после `Ya`, демо-сцена переведена на `Game`. Проверено Godot 4.7.2: `--editor --quit` и 120 кадров игры без ошибок; `check.py` без ошибок.
Решение: добавлен флаг `_loaded` — без него автосохранение до `Save.load_all()` могло затереть сохранение дефолтами.
Не проверено: телефон, облачные сохранения Яндекса, автосохранение по таймеру вживую (жду 15 с не стал).

T04: добавлены `tests/run_tests.gd` (96 проверок по T01-T04) и `tools/test.py`. Проверено: `python tools/test.py` → 96 проверок, 0 провалов, код 0; легендарных 0.56%, золотых 2.91% на 10000 бросков.
Решение: проверки вынесены из `_initialize` в первый кадр `_process` — в `_initialize` root ещё не в дереве, `_ready()` автозагрузок не вызван, и `Save.save_data()` падал на пустом `_timer`.
Не проверено: запуск на телефоне и в вебе; `GODOT_BIN` в системе не задан, тесты шли с временной переменной окружения.

T05: добавлены `WorldLayout` (единый источник позиций) и `WorldBuilder` (пол, забор, стены, линия броска, коридор из 5 полос, арки, свет, туман); в `main.gd` временная камера. Проверено Godot: 31 MeshInstance3D, 1 MultiMesh, 1 DirectionalLight, теней 0, 5 подписей арок; игра 180 кадров без ошибок.
Решение: размеры арок, кромки и столбиков забора тоже вынесены в `WorldLayout`; временная камера создаётся кодом, а не в `main.tscn` (в T06 её заменит `CameraRig`).
Не проверено глазами: цвета, туман, шашечный пол и читаемость названий зон; телефон и веб.

T06: добавлены `Avatar` (6 BoxMesh на шарнирах, ходьба/замах/подтягивание кодом), `CameraRig` (орбита 4-12 м, pitch -60..-5, follow_food, возврат) и `Player` (WASD/стрелки, 7 м/с, границы); временная камера T05 убрана.
Решение: движение относительно yaw камеры; корень `main.tscn` и демо-панель не перехватывают мышь, панель сдвинута в левый верх (в T13 удалится). Проверено Godot 4.7.2: 6 мешей, границы x 27 и z -2.5..55, ходьба 7 м/с, камера следует, мышь/колесо/кнопки работают; `check.py` 0 ошибок, `test.py` 96/0.
Не проверено глазами: у спавна камера стоит за задним забором, внизу кадра виден столб; на телефоне и в вебе не проверялось.

T07: добавлены `InputRouter` (тап, джойстик, камера, колесо, WASD, `enabled`) и `JoystickView` (`virtual_joystick.gd`: плавающий круг в `_draw`); ввод игрока и камеры переведён на сигналы роутера, временный `_unhandled_input` из `CameraRig` убран.
Решение: класс джойстика назван `JoystickView`, потому что в Godot 4.7 имя `VirtualJoystick` занято нативным классом (был Parse Error); эмулированная из касаний мышь (`DEVICE_ID_EMULATION`) игнорируется, а при включённом «Emulate Touch From Mouse» мышь не дублирует касание. Проверено временными headless-скриптами: 17 проверок ввода и 4 проверки эмуляции — 0 провалов; `check.py` 0 ошибок, `test.py` 96/0, игра 180 кадров без ошибок.
После проверки пользователем: джойстик камеры добавлен — теперь есть ДВА плавающих джойстика (`movement_joystick` слева, `camera_joystick` справа), сессии касаний разделены по половинам экрана; ранее поворот камеры был только перетаскиванием без собственного джойстика. Проверено временным headless-скриптом: 16 проверок (оба джойстика, два пальца, enabled, клавиатура, мышь, колесо) — 0 проваллов.
Не проверено вживую: касания на телефоне, «Emulate Touch From Mouse» в редакторе, ощущение чувствительности джойстиков и камеры.

T08: сделаны `scripts/ui/ui_style.gd` (outline_label, panel_style, make_icon_button, pulse), `scripts/ui/hud.gd` и `scenes/ui/hud.tscn`: деньги/сила/доход внизу слева, кнопки «Индекс»/«Магазин» слева и «Животные» справа, цель сверху, подсказка «Нажмите, чтобы бросить!»; подписка на `Game.money_changed`/`Game.strength_changed`, `set_goal`/`set_hint`/`set_mode`. Решение: кнопки делаются в коде через `UiStyle`, иконки из `assets/ui/icons/` по ключам с подстановкой первой буквы (файлов иконок ещё нет). Не проверено в игре: сам HUD, layout, значения после `add_money(100)`.

T09: сделаны `ThrowMeter` (шкала, ползунок-волна, `start/stop/get_value`), `ThrowController` (FREE→AIMING→THROWING→FLIGHT→LANDED, `landed`), `FoodView` (полёт по параболе), `Hud.set_flight`, `FoodData.color`, ключ `land_toast`. Решение: исправлены headless-ошибки Godot 4.7 — `Tween` это RefCounted (нет `add_child`), скругления StyleBox через `set_*_all`, `Label.font_size` только через тему. Проверено: игра 180 кадров без ошибок, `check.py` 0 ошибок, `test.py` 96/0.
Не проверено глазами: визуал шкалы/полёта/приземления, плашка «Зона, N м»; на телефоне и в вебе.

T10: исправлена ошибка «Cannot call non-static function "_make_placeholder()" from the static function "get_animal()"» — вспомогательные методы `ModelLoader` (`_make_placeholder`, `_animal_mat`, `_fit_to_size`, `_collect_aabb`) переведены в `static`. После фикса: headless без ошибок, `check.py` 0/0, `test.py` 96/0.
T10: исправлена ошибка при приземлении «Invalid call. Nonexistent function 'is_child_of' in base 'Node3D'» — в Godot 4 метод `Node` называется `is_ancestor_of`, а не `is_child_of`; в `AnimalView.set_creature` заменён на `is_ancestor_of(_model)`. После фикса: headless без ошибок, `check.py` 0/0, `test.py` 96/0.
