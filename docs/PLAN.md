# План: «Накорми зверей»

Рабочий индекс задач. Подробности каждой задачи находятся в отдельном файле `docs/tasks/Txx.md`. Справочные материалы разделены по темам в `docs/reference/`. Полный исходник без изменений сохранён в `docs/archive/PLAN_original.md`.

## Рабочий процесс

1. В новом чате попроси агента: `Выполни шаг Txx`.
2. Агент читает `CLAUDE.md`, `PROGRESS.md`, файл конкретной задачи и только перечисленные в нём справочники.
3. После реализации агент выполняет проверки и пишет отчёт с непроверенными пунктами.
4. Пользователь проверяет пункт «Тебе проверить». Только после команды «фиксируй» агент коммитит.
5. Одна задача за раз. Не переходить дальше, пока текущая не принята.

Метки источника в справочниках: **[скриншот]**, **[гайд]**, **[наше]**. Оригинал игры не запускался; пункты «Сверь с оригиналом» требуют отдельной проверки пользователем.

## Важные замечания

- `PROGRESS.md` остаётся отдельным файлом проекта и не создаётся из этого плана: его содержимое — журнал фактически выполненных работ.
- Подробные спецификации завершённых T00–T11 в исходном плане не раскрыты; сохранены только их названия и отметки выполнения. История фактических работ должна оставаться в `PROGRESS.md`.
- Исторические/заменённые спецификации сохранены в `docs/archive/SUPERSEDED_TASK_SPECS.md`. Не использовать их вместо активных задач.
- Обнаруженные несогласованности вынесены в `docs/OPEN_QUESTIONS.md`; их нельзя исправлять догадками.
