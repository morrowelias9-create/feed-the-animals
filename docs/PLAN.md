# План: «Накорми зверей» (3D-клон Throw Food For Animals для Яндекс Игр)

Правила для агента: `CLAUDE.md`. Что уже сделано: `PROGRESS.md`. Скриншоты оригинала: `docs/reference/` (`ref_01_base_hud.png` ... `ref_12_reveal_final.png`, список в R6).

## Как этим пользоваться (для тебя)

1. Дай агенту в **новом чате** фразу: «Выполни шаг T05 из PLAN.md». Он сам прочитает `CLAUDE.md`, шаг и нужные разделы справочника.
2. Агент сделает шаг, проверит себя и напишет отчёт.
3. Ты по пункту **«Тебе проверить»** в шаге запускаешь проект и смотришь глазами.
4. Всё хорошо: пишешь «фиксируй», агент делает коммит с названием из `PROGRESS.md`. Что-то не так: пишешь, что не так, агент правит в том же шаге.
5. Следующий шаг в новом чате.

Шаги идут по порядку. Одну задачу за раз. После шага T20 игра уже играбельна целиком: самое время собрать, залить черновик в консоль Яндекса и проверить на телефоне.

Метки в справочнике: **[скриншот]** видно на скриншотах, **[гайд]** взято из описаний игры в интернете, не проверено в игре, **[наше]** решение этого плана. Оригинал я запустить не мог, поэтому в шагах есть пункты «Сверь с оригиналом»: если твоя игра отличается, скажи агенту, поменяем.

## Справочник: дополнения версии 3

### R2 «Кинематика получения», редакция 3 (дополнение к фазам C и D)
- Фаза C: SCORE = очки удачи `luck`, накрутка 1.2 с, затем шаги размера по 0.35 с. Мигание не чаще 3 раз в секунду.

### R3, редакция 3: формулы [наше по мотивам гайда, числа свои, настраиваются симуляцией]
- **Дальность**: `dist = DIST_K * (strength + bonus)`, `DIST_K` = 4, бонус шкалы 0-20.
- **Треть зоны**: `f = (dist - start_m) / (end_m - start_m)`; `f < 1/3` потолок ранга 4, `f < 2/3` потолок 6, иначе 8.
- **Ранг**: вес `w(r) = exp(-(r - aim)^2 / (2 * 1.4^2))` для `r <= потолок`; `aim` = `aim_rank` еды, если еда этой зоны; если еда из прошлой зоны, `aim = 1`; если из будущей, `aim = 8`. Анти-повтор: вес последнего пойманного зверя / 50, предпоследнего / 2.5. В зоне 8 зверей, ранг = зверь.
- **Удача (SCORE)**: `luck = round(dist * food.luck * (1.25 если «Идеально!», иначе 1))`. Множитель шансов `lm = clamp(luck / zone.luck_ref, 0.6, 2.0)`, `zone.luck_ref` в `ZoneData`.
- **Мутация**: один `randf()`, шансы R4, умноженные на `lm` (сумма не выше 35%).
- **Размер**: `p = SIZE_P0 * lm` (`SIZE_P0` = 0.18); пока `randf() < p` и `k < SIZE_MAX` (10): `k += 1`, `p = min(p + 0.05, 0.4)`. Доход x`SIZE_STEP^(SIZE_POW * k)`, `SIZE_STEP` = 1.5, `SIZE_POW` = 1.8. Визуальный масштаб `min(1 + 0.22 * k, 2.6)`.
- **Доход**: `zone_base * RANK_STEP^(rank-1) * variant_mult * size_mult`, `RANK_STEP` = 1.5, `zone_base` = 1, 40, 1600, 64000, 2 560 000.
- **Продажа**: доход x30. **Загон**: вместимость 4, 6, 8, 10, 12, 14, 16, 18, 20; цены в `UpgradeData` (симуляция). **Рюкзак**: до 60 зверей вместе с загоном.
- **Сила**: `xp_needed(S) = 30 * XP_ZONE_K^(zone_of(4*S)) * (1 + S/40)`, `XP_ZONE_K` = 3.5; каждый турник x2 опыта.
- **Ориентиры темпа**: первый турник и яблоко за 1-2 мин, Саванна 8-12 мин, Пустыня 35-50 мин, Джунгли 2-3 ч, Океан 6-9 ч.

### R2. Игровой цикл и управление

**Состояния броска** (одно действие за раз):

| Состояние | Что происходит |
|---|---|
| `FREE` | Игрок ходит, HUD виден |
| `AIMING` | Игрок в зоне броска, на экране шкала, ползунок ходит вверх-вниз (период 1.4 с туда-обратно). Кнопки, деньги и цель скрыты, остаётся сила. Подсказка внизу «Нажмите, чтобы бросить!» [скриншот 4] |
| `THROWING` | Замах 0.3 с, еда вылетает |
| `FLIGHT` | Еда летит по дуге, камера следует. Время `clamp(0.9 + dist / 500, 0.9, 3.0)` с |
| `LANDED` | Эффект приземления, плашка «Саванна, 187 м» (держится 1.2 с поверх начала `REVEAL`) |
| `REVEAL` | Кинематика получения зверя, четыре фазы (ниже). Игрок не управляет, HUD скрыт. Зверь добавляется игроку в начале фазы C (автоматически, в свободное место, иначе в инвентарь) [скриншоты 10-12] |
| `COOLDOWN` | 0.6 с, камера возвращается, затем `AIMING` (если игрок в зоне) или `FREE` |

Целевое время цикла 8-10 секунд с кинематикой, тап её ускоряет. Вход в зону запускает `AIMING` сам, движение его отменяет [наше].

**Кинематика получения** [скриншоты 10-12, времена и числа наши]. Зверь выбирается `SpawnRoller.roll` в начале. Камера в режиме `scripted`.
- **Фаза A «Глаза зверя»** (`REVEAL_EYES_S` = 1.6 с). Камера на высоте глаз зверя `max(0.35, 0.45 * size_m)`, стартует в 12 м от еды, смотрит на еду вниз под -25°, к концу -40°, и приближается до 1.2 м (`ease_out`). Покачивание шагов: вертикально ±0.12 м (для крупных зверей пропорционально размеру), крен ±3°, частота 3 Гц; поле зрения 75 → 68. По краям экрана виньетка (радиальный градиент, до 45% чёрного). Еда лежит на полу и медленно вращается. Плашка зоны из `LANDED` видна сверху.
- **Фаза B «Сбоку и имя»** (до `REVEAL_SIDE_S` = 1.2 с, затем ждёт конца печати). Мгновенный срез: камера сбоку на высоте `0.5 * size_m`, на расстоянии `3.2 * size_m`, перпендикулярно направлению бега. Зверь вбегает в кадр слева и останавливается у еды (еда лежит между камерой и зверем, как на `ref_11`). Внизу экрана белые чёрточки с чёрной обводкой по числу букв названия; буквы появляются по одной в случайном порядке с интервалом `REVEAL_LETTER_S` = 0.12 с, каждая «вспрыгивает» (масштаб 1.4 → 1 за 0.1 с), звук `type`.
- **Фаза C «Итог»** (до тапа, не дольше `REVEAL_AUTO_S` = 8 с). Камера за 0.4 с плавно переходит на вид 3/4 спереди: расстояние `4 * size_m`, высота `0.6 * size_m`, зверь поворачивается к камере. Здесь вызывается `Game.add_animal`. Экран: заголовок «Удача!» (если вариант не обычный или редкость 3-4) с лучами за ним, «SCORE N» (N это дальность броска в метрах [наше]), название варианта (если есть) его цветом, название зверя крупно цветом редкости, под ним мелко редкость словом, доход «$6/s» зелёным, внизу «Нажмите, чтобы продолжить». Эффекты варианта (свечение, искры) работают.
- **Фаза D «Выход»** (0.6 с). Тап: зверь съедает еду (0.3 с, еда уменьшается), вспышка, зверь уменьшается до нуля, UI гаснет, камера `return_to_player(0.6)`, `finish()`. Следом зверь появляется в загоне игрока (T11).
- **Пропуск и защита**: тап в A или B сразу переходит к C (имя показывается целиком); после перехода тапы игнорируются 0.25 с, чтобы не пролистать итог случайно; окна и кнопки HUD в `REVEAL` недоступны.

**Ввод** (весь в `InputRouter`):
- Короткое нажатие (меньше 0.25 с, сдвиг меньше 20 px, не по кнопке) = «действие»: в `AIMING` бросок, в зоне турника повторение.
- Перетаскивание в левой половине экрана: плавающий джойстик (появляется в точке касания, радиус 80 px, исчезает при отпускании). В правой половине: поворот камеры.
- Компьютер: WASD и стрелки ходят, пробел или клик = «действие», перетаскивание мышью вертит камеру, колесо меняет дистанцию камеры (4-12 м).
- Кнопки интерфейса поглощают касания, начавшиеся на них.

**Камера**: орбитальная от третьего лица, дистанция 7 м, наклон 25° вниз, поле зрения 70. В `FLIGHT` следует за едой (10 м позади, 5 м выше), в `REVEAL` ею управляет `RevealController` (ниже), в `COOLDOWN` возвращается к игроку за 0.8 с.

**Аватар**: блочный человечек из `BoxMesh` (голова, торс, две руки, две ноги), анимация кодом: ходьба, стойка, замах, подтягивание. Скорость 7 м/с. Модель аватара не планируется.

### R3. Формулы и числа

Числа в `GameConfig`: `DIST_K=4.0`, `BONUS_MAX=20`, `SELL_MULT=30`, `INV_LIMIT=60`, `OFFLINE_CAP_S=7200`, `OFFLINE_RATE=0.5`, `OFFLINE_MIN_S=60`, `BOOST_S=300`, `BOOST_MAX_S=1800`, `BOOST_MULT=2`, `AUTOSAVE_S=15`, `INDEX_REWARD_BASE=5000`, `NEED_A=10`, `NEED_B=4`, `NEED_C=60`, `TIER_LUCK=0.25`, `BAR_REP_INTERVAL=0.25`, `FX_ENABLED=true`, `REVEAL_EYES_S=1.6`, `REVEAL_SIDE_S=1.2`, `REVEAL_LETTER_S=0.12`, `REVEAL_AUTO_S=8.0`, `RARITY_INCOME=[1,3,10,40,200]`, `BASE_W=[70,20,7,2.5,0.5]`, `SIZE_BY_RARITY=[1.2,2.2,3.5,5.0,7.0]`.

Эти числа стартовые [наше], проверены грубой симуляцией `python tools/sim_economy.py`. Меняешь число в игре, меняй и в симуляторе.

- **Бросок** [скриншот 4: шкала и «+11»; формулы наши]. Ползунок `v` от 0 (низ) до 1 (верх). `bonus = round(20 * v)` [гайд: бонус до +20 у верха шкалы]. `eff = strength + bonus`, `strength` целое, старт 1. `dist = 4 * eff` м. `bonus >= 19` называется «Идеально!». Зона: последняя из `ZONES`, у которой `start_m <= dist`.
- **Какой зверь**: зона по дальности; редкость `r` (0-4) по весам `BASE_W[r] * (1 + 0.25 * tier)^r`, `tier` это выбранная еда 0-9; зверь из зоны и редкости равновероятно; вариант по `VariantData` (R4): бриллиантовый 1%, золотой 3%, иначе обычный. Для справки: доля легендарного 0.5% на тире 0, 3.2% на тире 3, 11.1% на тире 7, около 16% на тире 9.
- **Доход**: `income = mult_зоны * RARITY_INCOME[r] * VariantData.mult(variant)`. Доход идёт только от зверей в загонах, начисляется каждый кадр по `delta`.
- **Продажа**: `income * 30`. Лимит инвентаря 60 (все звери, стоящие и нет); при переполнении новый зверь продаётся автоматически с сообщением.
- **Сила**: одно повторение даёт `BAR_XP[bar_tier]` опыта. Для силы `S` следующий уровень требует `10 + 4 * S * (1 + S / 60)` опыта, лишнее переносится.
- **Участок**: старт 4 слота, расширение +2, шесть расширений за 600, 8 000, 100 000, 1 200 000, 15 000 000, 200 000 000, максимум 16. Табличка показывает «текущее > новое» и цену [скриншот 1].
- **Оффлайн**: `min(прошло, 7200 с) * доход_размещённых * 0.5`, окно при входе, если прошло больше 60 с.
- **Буст**: rewarded «x2 доход на 5 минут». `boost_until = max(now, boost_until) + 300`, не больше `now + 1800`.
- **Индекс**: зверь заносится при первом получении (вариант отдельно не учитывается). Награда за полную зону: `5000 * mult_зоны` денег один раз.
- **Ориентиры темпа** (симуляция, «разумный игрок», цель настройки, не гарантия): яблоко около 1 мин, первое расширение около 2 мин, Саванна около 7 мин, Пустыня 25-30 мин, Джунгли 2-3 ч, Океан 9-10 ч.

### R7. Реклама, лидерборд, языки

- **Rewarded**: x2 оффлайн-дохода, x2 доход на 5 минут. Только по явной кнопке игрока.
- **Interstitial**: на состоянии `COOLDOWN` после получения зверя, если с прошлой рекламы было не меньше 12 бросков и не меньше 180 секунд, и после любой rewarded не меньше 60 секунд. Не на старте, не при `AIMING`, не при открытом окне. Дополнительно ограничивает `Ya`.
- **Лидерборд** `best_throw` (метры, int): при новом рекорде, не чаще раза в 5 секунд. Создать в консоли разработчика с таким именем.
- **Языки**: ru и en полностью. Названия зверей, еды, зон, редкостей, все кнопки и подсказки через `Loc.t()`. Ключи: `zone_<id>`, `food_<id>`, `animal_<id>`, `rarity_0`...`rarity_4`, `gold`, плюс ключи окон и подсказок.

### R8. Ассеты (для тебя: что генерировать)

Игра не ждёт арт: пока файла нет, показывается заглушка, подмена идёт по **имени файла**. Название, логотип и иконки игры должны быть свои (это нужно и для модерации). Что делается кодом без арта: аватар, заборы, стены, земля, плиты, стрелки, маркеры, линия броска, турники, деревья-заглушки, небо.

**Общий стиль**: игрушечные «кубиковые» модели в духе конструктора: блочные формы, чуть видимые круглые шипы, чистые насыщенные цвета без реалистичных текстур, читаемый силуэт издалека. Иконки: мультяшные глянцевые с толстой тёмной обводкой, яркие цвета, один предмет по центру.

**Звери, 40 штук** (`assets/models/animals/<id>.glb`, id из R4): формат `.glb`, одна меша, один материал, текстура до 512x512 (лучше без текстуры), не больше 3000 треугольников (легендарные до 5000), начало координат на земле под центром, зверь смотрит в **-Z**, Y вверх, без скелета и анимаций (движение делается в коде). Масштаб файла не важен, важны пропорции и что модель цельная. Порядок генерации: сначала 8 зверей Леса, потом по зоне. Запрос (подставь животное):
> low-poly blocky toy-brick style [animal], single character, saturated clean colors, rounded blocky shapes, slight round studs on surfaces, neutral standing pose, side-3/4 view, plain background, game asset

Рекомендуемый путь: нейросеть для 3D по картинке или тексту, потом в Blender упрощение (Decimate до нужного числа треугольников, один материал), экспорт в `.glb`.

**Еда, 10 штук**: модель `assets/models/food/<id>.glb` до 1000 треугольников, размер 0.3-0.6 м, и иконка `assets/ui/icons/food_<id>.png`. id: `carrot apple banana toast orange cheese bread watermelon pizza cake`.

**Иконки интерфейса** (PNG 256x256, прозрачный фон, `assets/ui/icons/`): `index` (синяя книга с закладкой), `shop` (красная корзина), `animals` (оранжевая лапа), `strength` (жёлтая согнутая рука), `money` (зелёная пачка денег), `paw` (маленькая лапа), `close` (крестик), `lock` (замок), `bar_wood`, `bar_steel`, `bar_gold`, `bar_blue`, `bar_purple`, по желанию `rarity_0`...`rarity_4` (рамки карточек). Запрос:
> glossy cartoon mobile game icon of [object], thick dark outline, saturated colors, centered, transparent background, no text
