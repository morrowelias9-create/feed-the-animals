# План релиза: «Накорми зверей»

Рабочий индекс задач до релиза демо и после него. Подробности каждой задачи находятся в отдельном файле `docs/tasks/release/Txx.md`, общие правила для них — в `docs/tasks/release/_RULES.md`, инструкция по новым биомам — в `docs/reference/R11_NEW_BIOME.md`. Полный исходник без изменений сохранён в `docs/archive/PLAN_RELEASE_original.md`.

Этот план не меняет `PLAN.md`, `PLAN_WORLD.md` и `PLAN_POLISH.md`. Он закрывает незакрытые T21, T25, T28, T29 из `docs/PROGRESS.md` и добавляет новые задачи. Нумерация продолжается с **T54** (T30–T53 заняты планами `docs/PLAN_POLISH.md` и `docs/PLAN_WORLD.md`). Если появится `PLAN_LONGPLAY.md`, его задачи нужно перенумеровать после этого плана.

## Рабочий процесс

1. В новом чате попроси агента: `Выполни шаг Txx`.
2. Агент читает `CLAUDE.md`, `docs/tasks/release/_RULES.md`, `docs/PROGRESS.md`, файл конкретной задачи и только перечисленные в нём справочники.
3. После реализации агент выполняет проверки и пишет отчёт с непроверенными пунктами.
4. Пользователь проверяет пункт «Тебе проверить». Только после команды «фиксируй» агент коммитит.
5. Одна задача за раз. Не переходить дальше, пока текущая не принята.
6. Перед запуском задачи для неё должен существовать подробный файл `docs/tasks/release/Txx.md`. Если его нет, сначала составляем его вместе.

## Где мы сейчас

**Уже работает.** Ядро и мир из 5 биомов, бросок и выбор зверя, экономика, загон, лавка, окна «Животные» и «Индекс», еда, тренировка, расширение загона, обучение, ru/en. Яндекс-слой: буст x2, реклама, лидерборд, инап-покупки, соседи, удалённые флаги. 40 зверей по частям, 15 видов еды, мутации и размеры, мини-зоны, питомцы за полный Индекс, полировка 1–8.

**Что мешает выпустить демо:**

- Бюджет «не больше 100 мешей в кадре» вероятно превышен, но не измерялся.
- Часть проверок красная: `T24f parrot`, `flight_time`, `ZoneBadge`/`Loc` в headless, 3–4 ошибки `check.py` про иконки `animal_*`, 1 ошибка `check_loc.py` (`carry_place`).

- Репозиторий публичный, а в нём мусор в корне, дубль раздела «Главные правила» в `CLAUDE.md` с противоречием про `git push`, локальные пути Windows и тема ntfy в `tools/ntfy_topic.txt`.

## Решения владельца

Эти вопросы нужно закрыть до соответствующих задач. Без ответа агент не должен угадывать.

1. Целевой темп демо → нужно до **T63**.
2. Доля «особых» находок и судьба `SIZE_P0` → нужно до **T65**.
3. Награда за вход в мини-зону: оставить, уменьшить или заменить → **T60**.
4. Питомец Джунглей: горилла (ранг 8) или «Призрачный ягуар» (ранг 6) → **T60**.
5. Язык `tr`: заполнять или убрать → **T60**.
6. Ежедневная награда и таблица лидеров по доходу: по умолчанию не в демо, после релиза.

## Важные замечания

- Правила работы агента прежние (`CLAUDE.md`): один шаг за раз, коммит только по слову «фиксируй».
- Требования модерации и размера сборки Яндекса каждый раз перечитывать в консоли, не брать из памяти.
- После релиза данные существующих биомов не менять. Поля `Save.DEFAULTS` не удалять и не переименовывать без миграции, массивы в сохранении расширять только миграцией.
- Любую подстройку баланса после релиза делать **только через удалённые флаги**, без новой сборки.
- Обнаруженные несогласованности записывать в `docs/OPEN_QUESTIONS.md`, не исправлять догадками.
