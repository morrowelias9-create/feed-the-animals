# T24e. Рецепты зверей: остальные зоны

**Назначение:** дописать рецепты оставшихся 32 зверей в стиле T24d. Игровая логика не меняется.

**Зависит от:** T24d (выполнен и принят пользователем).
**Читать:** `R8_ASSETS.md` (разделы 1, 2, 5, 9), `R4_DATA.md` (список зверей и размеров).
**Файлы для изучения перед работой (только они):** `scripts/data/animal_recipes.gd`, построитель из T24d, `tests/run_tests.gd` (проверки рецептов).

## Как выполнять

Одна зона за запуск. Пользователь пишет `Выполни T24e Саванна` (или Пустыня, Джунгли, Океан). Агент делает только указанную зону, отчитывается и ждёт проверки. Каждая зона принимается и фиксируется отдельно, поэтому в `PROGRESS.md` у T24e четыре отметки.

| Подшаг | Зона | Звери |
|---|---|---|
| T24e-1 | Саванна | `hyena`, `zebra`, `antelope`, `giraffe`, `ostrich`, `rhino`, `elephant`, `lion` |
| T24e-2 | Пустыня | `lizard`, `scorpion`, `jackal`, `fennec`, `camel`, `monitor`, `vulture`, `cobra` |
| T24e-3 | Джунгли | `parrot`, `monkey`, `tapir`, `koala`, `python`, `jaguar`, `tiger`, `gorilla` |
| T24e-4 | Океан | `seahorse`, `crab`, `jellyfish`, `turtle`, `mantis_shrimp`, `dolphin`, `shark`, `orca` |

## Что входит в задачу

1. Рецепты зверей выбранной зоны в `scripts/data/animal_recipes.gd` по правилам R8 раздел 5 (фаски, перекосы, матовые вершинные цвета, чек-лист 5.4). Каждый зверь узнаваем по силуэту, не похож на других видов зоны и других зон.
2. Типы движения (`move`) по виду: прыжок, переваливание, рысь, плавание, змеиное движение. Если не хватает типа, добавить его в `AnimalView` минимальным способом и записать «решение» в «Журнал».
3. Пропорции и размеры: итоговый размер даёт `size_m` из `AnimalData`; рецепты не меняют его.
4. Тесты T24d расширяются на зверей зоны (треугольники, детерминизм, основание на земле, направление -Z, пять вариантов). Для змей, рыб и медузы направление взгляда проверяется по группе `head`; исключения помечаются в рецепте.

## Жёсткие ограничения

Те же, что в T24d (раздел «Жёсткие ограничения»). Дополнительно не менять рецепты зверей предыдущих зон, если пользователь не просил.

## Проверки

`python tools/check.py`, `python tools/test.py`, Godot 4.7.2 `--headless --path . --editor --quit` (прочитать весь вывод), запуск `scenes/debug/zoo.tscn`.

## Тебе проверить

1. Зоопарк: каждый зверь зоны виден в игровой дистанции, мордой вперёд, на земле, нормального размера.
2. Режим «силуэт»: звери зоны различаются без цвета.
3. Чек-лист R8 5.4 (не похоже на Roblox) и палитра подходит к биому.
4. Все пять вариантов выглядят нормально.
5. В игре: брось на нужную дальность, дождись зверя зоны, проверь экран получения и загон.
