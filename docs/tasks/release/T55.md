# T55 — `docs/PROGRESS.md` по факту

Прочитай `docs/tasks/release/_RULES.md`, `CLAUDE.md`, `docs/PROGRESS.md`. Задача T54 должна быть выполнена.

**Зачем.** Отметки «сделано» и «зафиксировано» в `docs/PROGRESS.md` расходятся с историей git. Агенты верят этому файлу, поэтому в нём должна быть правда.

**Трогаем только** `docs/PROGRESS.md`. Эта задача прямо разрешает менять структуру файла (в `CLAUDE.md` разрешены только отметки и «Журнал»). Код не трогаем.

## Формат записи в этом файле (повторяй точно)
```
- [x] **T24c** Удалённые флаги
  - коммит: `T24c: удалённые флаги (Remote Config)`
  - зафиксировано: да
```
Сначала `[ ]` или `[x]`, затем жирный номер, название, ниже две строки с отступом в два пробела.

## Шаги

### 1. Собери факты из git
`git log --oneline --no-decorate > .tmp\log.txt` (папка `.tmp\` в `.gitignore`). Для каждой задачи в чеклисте возьми название из строки `коммит:` и найди его: `git log --oneline --grep="название коммита" -F`. Запомни: коммит есть или нет.

### 2. Составь таблицу расхождений
Для каждой задачи у которой «зафиксировано: да», а коммита с таким названием **нет**, или наоборот («нет», а коммит есть) — строка `Txx — в журнале ..., по git ...`. Обязательно проверь: T16, T19, T21, T24c, T24e и её четыре подзадачи (`T24e: звери Саванны`, `...Пустыни`, `...Джунглей`, `...Океана`), T25, T28, T29. Известно заранее:
- T24c записана **дважды**: в M1 (`[ ]`, «нет», название `T24c: удалённые флаги`) и в M3 (`[x]`, «да», название `T24c: удалённые флаги (Remote Config)`). Оставить надо вариант из M3, если такой коммит есть в git; блок в M1 удалить.
- T24e: у основной строки стоит `[ ]` и «зафиксировано: нет», затем четыре подпункта `[x]`, затем **ещё одна** строка «зафиксировано: да». Если все 4 коммита есть в git, T24e закрыта: `[x]`, одна строка «зафиксировано: да», лишнюю убрать.
- T16 и T19 стоят `[x]` с «зафиксировано: нет». Если коммит с их названием есть в git — «да», если нет — оставить «нет».
- T21, T25, T28, T29 не закрыты, не менять (их закрывают T59, T67 и T70–T72).

### 3. СТОП: спроси владельца
Покажи таблицу расхождений и спроси: «Исправить эти отметки по git? (да / нет / список исключений)». Жди ответа.

### 4. Исправь
- Для подтверждённых строк поправь отметки и «зафиксировано».
- Удали дубль T24c (блок в M1), закрой T24e.
