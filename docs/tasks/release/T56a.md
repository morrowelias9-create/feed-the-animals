# T56a — Отладочная панель

Прочитай `docs/tasks/release/_RULES.md`, `CLAUDE.md`, `docs/PROGRESS.md`, `scripts/debug/zoo.gd` (образец отладочного кода), `docs/reference/R5_SAVE.md`.

**Зачем.** Сейчас в `scripts/debug/` лежит только зоопарк зверей. Для проверок T58–T72 нужны инструменты: сбросить сохранение, выдать деньги, перенестись в биом, подвинуть время для оффлайна. Делаем их **один раз** и только для отладочной сборки.

**Трогаем:** новый `scripts/debug/debug_panel.gd`, подключение в `scenes/main.gd`, одна строка в `CLAUDE.md`. Игровую логику не меняем.

## Правила
- Панель создаётся **только если** `OS.is_debug_build()` равно `true`. В релизной сборке её нет вообще: не создаётся и не занимает память.
- Видимый текст панели может быть без `Loc` (одно исключение из правила про `Loc`, запиши его в `CLAUDE.md` одной строкой).
- Панель не должна мешать игре: по умолчанию скрыта.
- Открытие: клавиша `F9` на компьютере; на телефоне — пять быстрых нажатий (в течение 2 секунд) в левый верхний угол экрана, квадрат 64×64.
- Кнопки не меньше 64×64. Панель рисуется кодом в своём `CanvasLayer` (слой 40), без `.tscn`.
- В `project.godot` ничего не добавлять (`InputMap` и действия не нужны: читай `KEY_F9` в `_unhandled_key_input`).

## Кнопки (все вызывают существующие методы `Game`/`Save`; не копируй их логику)
1. «Сбросить сохранение»: перезаписать сохранение значениями `Save.DEFAULTS`, сохранить, перезагрузить сцену (`get_tree().reload_current_scene()`). Спрашивает подтверждение вторым нажатием.
2. «+деньги ×10»: `Game.add_money(max(Game.money * 9, 1000))` (деньги растут примерно в 10 раз).
3. «+сила 10»: через существующий метод повышения силы/опыта (найди `grep -n "func add_xp\|func add_strength" autoload/game.gd`; если нужного метода нет — напиши в отчёте, кнопку не делай).
4. «В биом N»: пять кнопок «Биом 1…5» (число берётся из `ZoneData`): ставит игрока в точку `-start_z` начала биома, камера следует. Используй существующий способ телепортации игрока (`Player`).
5. «+5 счастливых бросков»: `Save.data["lucky_throws"] += 5`, сохранить.
6. «Время назад на 1 час»: сдвигает `last_seen` в сохранении на 3600 с назад (для проверки оффлайна; после этого нужно закрыть и открыть игру; подскажи это на панели).
7. «Показать FPS и меши»: включает плашку из T67 (если T67 не сделана, кнопка есть, но плашки нет: показывает `Engine.get_frames_per_second()`).
8. «Флаг zones_open»: поле ввода числа, которое локально переопределяет значение флага (до T62 просто сохраняет число в переменной панели, T62 подключит).

## Проверка
Запусти проверки из `_RULES.md`. Игра с панелью запускается, `F9` открывает/закрывает, кнопки 1–6 работают. `grep -rn "is_debug_build" scripts scenes` показывает, что панель создаётся только в отладке. Проверь `tools/build.py` и `export_presets.cfg`: релизный экспорт отладочной сборкой **не** является (в отчёте: какой режим экспорта у веб-сборки: `debug` или `release`; если `debug` — это **проблема**, опиши, как включить релизный экспорт, но не меняй `export_presets.cfg` без вопроса).

## Тебе проверить
1. `F9` открывает панель. «Сбросить сохранение» (два нажатия) начинает игру с нуля.
2. «+деньги ×10», «+сила 10», «Биом 3» делают то, что написано.
3. В релизной сборке (когда будет) панели нет.

**Готово, когда:** панель работает, в релизе её нет, режим экспорта веб-сборки описан в отчёте.
