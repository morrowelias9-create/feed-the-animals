# T63 — Целевой темп демо

Прочитай `docs/tasks/release/_RULES.md`, `CLAUDE.md`, `docs/PROGRESS.md`, `docs/reference/R3_BALANCE.md`. Задача T57 должна быть выполнена (симулятор читает числа из игры).

**Зачем.** После релиза числа первых пяти биомов заморожены. Сначала нужно решить, **сколько времени** игрок проводит в каждом биоме, и записать это числами. Эти числа — цель для T64.

## Шаги

### 1. Измерь, как сейчас
Запусти `python tools/sim_progress.py` (режим «активный» и режим «30 минут в день»). Выпиши в отчёт таблицу:
| Событие | Часы (активный) |
| вход в биом 2, 3, 4, 5 | ... |
| куплена вся еда | ... |
| дней по 30 минут в день до конца | ... |
Ориентир из журнала (после «ровной редкости»): входы 0,54 / 1,35 / 2,47 / 3,87 ч, конец Океана (мини-зона 5.6) 5,87 ч. Старые цели в симуляторе были 0,5 / 1,3 / 2,5 / 4,0 / 6,0.

### 2. СТОП: спроси владельца
Покажи текущую таблицу и предложение:
| Событие | Цель, ч (допуск ±10 %) |
|---|---|
| вход в биом 2 (мини-зона 2.1) | 0,5 |
| вход в биом 3 (3.1) | 1,5 |
| вход в биом 4 (4.1) | 3,0 |
| вход в биом 5 (5.1) | 5,0 |
| конец пути (мини-зона 5.6) | 7,5 |
| куплена вся еда | 10 |
Предложение рассчитано так, чтобы активный игрок не заканчивал демо за один вечер.
Задай вопросы одним сообщением:
1. «Принять эти цели или поменять числа?»
2. «Это означает, что демо будет длиннее нынешних 5,87 ч примерно в 1,3 раза, а темп вырастет по всем веткам. Согласен?»

### 3. Запиши
В `docs/reference/R3_BALANCE.md` добавь раздел «Целевой темп демо» с принятой таблицей, допуском ±10 % и датой решения. Добавь строку «режим 30 минут в день: цель не задана, считается по симулятору». Ничего в коде не меняй.

## Проверка
Файл `R3_BALANCE.md` содержит таблицу целей, числа совпадают с ответом владельца.

1. Открой `R3_BALANCE.md` и убедись, что цифры твои.
