# T69 — Телефон и веб

Прочитай `docs/tasks/release/_RULES.md`, `CLAUDE.md`, `docs/PROGRESS.md`, `docs/reference/R6_UI.md`, `docs/reference/R7_YANDEX.md`.

**Зачем.** Игра идёт в браузере на телефоне. Типичные поломки: страница прокручивается пальцем, случайный зум, кнопки под вырезом экрана, игра не сохраняется, когда вкладку свернули.

## Шаги

### 1. Страница `web/shell.html`
Проверь и при необходимости исправь:
1. В `<head>` есть `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no, viewport-fit=cover">`.
2. В CSS для `html, body, canvas`: `touch-action: none; overscroll-behavior: none; -webkit-user-select: none; user-select: none; -webkit-touch-callout: none; -webkit-tap-highlight-color: transparent;`
3. Нет прокрутки: `html, body { margin: 0; height: 100%; overflow: hidden; }`.
4. Правая кнопка мыши не открывает меню на холсте: `canvas.addEventListener('contextmenu', e => e.preventDefault())`.

### 2. Безопасные зоны (вырез экрана)
Найди, как интерфейс задаёт поля от краёв экрана (`grep -rn "safe" scripts`). Проверь, что кнопки HUD не заходят под вырез/полосу жестов: отступ берётся из `DisplayServer.get_display_safe_area()` или CSS `env(safe-area-inset-*)`. Если не учтено — исправь.

### 3. Размеры кнопок
Все кнопки, на которые нажимает игрок, не меньше **64×64** пикселей. Напиши скрипт-проверку `tools/check_ui_sizes.gd` (или добавь в существующую проверку): строит окна и HUD, ищет `Button`/`TextureButton` с минимальным размером меньше 64×64, печатает их пути. Исправь найденные.

### 4. Пауза и сохранение при уходе в фон
Проверь в автозагрузке `Game`: при `NOTIFICATION_APPLICATION_FOCUS_OUT`, `NOTIFICATION_WM_WINDOW_FOCUS_OUT` и `NOTIFICATION_APPLICATION_PAUSED` происходит (1) сохранение игры, (2) пауза звука, (3) запись времени `last_seen` для оффлайн-дохода. При возврате — снятие паузы. Если чего-то нет — добавь. Не рисуй новых окон.

### 5. Консоль браузера
В отладочной веб-сборке в Chrome открой DevTools → Console. Не должно быть красных ошибок при старте, броске, открытии каждого окна. Для каждой найденной ошибки: опиши и исправь, если ошибка в нашем коде; если ошибка от движка/SDK — запиши в отчёт.

### 6. Тексты
`python tools/check_loc.py` без ошибок (ru и en заполнены).

## Проверка
Все проверки из `_RULES.md`.

## Тебе проверить (на телефоне, в браузере)
1. Палец по экрану вне кнопок не прокручивает страницу. Двойной тап и щипок не зумят.
2. Поверни телефон (если игра допускает поворот): интерфейс не ломается.
3. Все кнопки читаются, нажимаются большим пальцем, ничего не под вырезом.
4. Сверни вкладку на 10 секунд и вернись: игра не «ускорилась», деньги не пропали.
5. Обнови страницу посреди игры: прогресс на месте.
6. Переключи язык телефона на английский и русский: тексты на месте.

**Готово, когда:** пункты 1–6 «Тебе проверить» пройдены, в консоли браузера нет ошибок нашего кода.
