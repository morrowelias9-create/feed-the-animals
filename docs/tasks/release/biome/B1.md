# B1 — Паспорт биома

Запуск: `Выполни B1 для биома <id>` (номер биома и id называет владелец).
Прочитай `docs/tasks/release/_RULES.md`, `docs/reference/R11_NEW_BIOME.md`, паспорта предыдущих биомов `docs/biomes/`.

**Зачем.** Паспорт — один файл со всем, что нужно знать о биоме. Дальше все шаги работают по нему и ничего не придумывают.

## Шаги
1. Если файла `docs/biomes/NN_<id>.md` нет — `python tools/new_biome.py <id> <N>`. Если инструмента нет — скопируй `docs/biomes/_TEMPLATE.md` вручную.
2. Прочитай паспорт предыдущего биома и `docs/biomes/_TEMPLATE.md`.
3. **СТОП: спроси владельца** одним сообщением: «Название биома ru/en, тема и настроение, основные цвета (пол, стена, небо, туман), особая механика (если есть)». Если что-то из этого не названо — предложи 2 варианта и жди выбора.
4. Предложи (не решай) состав биома владельцу по таблицам шаблона: 8 зверей (ранги 1–8, движение: trot/waddle/swim/slither/…, размер), 3 еды, турник, 6 мини-зон, питомец (зверь ранга 8), декор. Для каждого пункта — один вариант и короткое обоснование. Звери должны отличаться от зверей других биомов.
5. Заполни паспорт утверждёнными вариантами. Числа (границы, `base`, `mult`, `luck_ref`, цены, `luck`) оставь пустыми — их считает B2.
6. Покажи паспорт владельцу и жди слова «утверждаю».

## Что не делать
Не трогай код и данные. Не придумывай числа.

## Тебе проверить
1. Прочитай паспорт, поправь названия и состав.

**Готово, когда:** паспорт заполнен без чисел, владелец написал «утверждаю».
