# B4 — Звери

Запуск: `Выполни B4 для биома <id>`. Паспорт: `docs/biomes/NN_<id>.md`. Требуется B3.
Прочитай `docs/tasks/release/_RULES.md`, `docs/tasks/T24d.md`, `docs/tasks/T24f.md`, `docs/reference/R8_ASSETS.md`, рецепты соседнего биома в `scripts/data/recipes/`.

**Зачем.** Звери строятся кодом (рецепты). Нужно 8 рецептов и 8 иконок.

## Шаги
1. Открой рецепты соседнего биома и один тест рецептов — это образец. Повторяй структуру и стиль.
2. Создай `scripts/data/recipes/<id>.gd` с 8 рецептами. Для каждого зверя из паспорта:
   - тип движения (из паспорта);
   - число треугольников не выше лимита (лимит в `R8_ASSETS.md` и в тесте рецептов);
   - звери стоят на земле (нижняя точка модели на уровне пола);
   - зверь смотрит в направлении **−Z**;
   - 5 вариантов вида (обычный, золото, бриллиант и остальные — как у зверей других биомов);
   - анимация по частям для всех 3 режимов (T24f).
3. Иконки: `assets/ui/icons/animal_<animal_id>.png` для каждого зверя. Если иконки создаются автоматически (скриншот модели или скрипт) — найди как (`grep -rn "animal_" tools`) и запусти. Если нужны нарисованные — `СТОП: спроси владельца`, дай список id.
4. Запусти тесты рецептов и `python tools/check_assets.py`.
5. Подключи рецепты там, где подключены рецепты других биомов (найди `grep -rn "recipes" scripts`).

## Что не делать
Не меняй рецепты других биомов. Не поднимай лимит треугольников.

## Проверка
Тесты рецептов, `check_assets.py`, `check_biome.py <id>` (пункты про зверей) без ошибок.

## Тебе проверить
1. Открой зоопарк (отладка), найди 8 новых зверей. Проверь **все 3 режима** частей: звери целые, ходят/плавают правильно, смотрят вперёд, не висят в воздухе и не проваливаются.

**Готово, когда:** тесты рецептов и `check_assets.py` без ошибок, звери просмотрены в зоопарке.
