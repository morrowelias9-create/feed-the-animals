# B8 — Тесты и симуляция

Запуск: `Выполни B8 для биома <id>`. Паспорт: `docs/biomes/NN_<id>.md`. Требуются B3–B7.
Прочитай `docs/tasks/release/_RULES.md`.

## Шаги
Запусти по порядку и сохрани результаты:
1. `python tools/check.py`
2. `python tools/check_loc.py`
3. `python tools/check_assets.py`
4. `python tools/test.py`
5. `python tools/check_biome.py <id>`
6. `godot --headless --path . --editor --quit`
7. `python tools/dump_data.py`, затем `python tools/sim_progress.py` в режимах «активный» и «30 минут в день».
8. Стенд редкости T65 (`tools/rarity_stand.gd`) для нового биома: доля особых находок в пределах цели из `R3_BALANCE.md` (±2 процентных пункта).
Каждую ошибку исправь, затем повтори проверку. Если ошибка не из-за нового биома — запиши в «Уже было красным» и не чини.

## Проверка
Результаты таблицей в отчёте.

## Тебе проверить
Прочитай таблицу, убедись, что нигде нет ❌.

**Готово, когда:** нет ошибок, нет новых падений, симулятор и стенд редкости в целях.
