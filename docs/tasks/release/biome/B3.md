# B3 — Данные и тексты

Запуск: `Выполни B3 для биома <id>`. Паспорт: `docs/biomes/NN_<id>.md`. Требуются B1 и B2.
Прочитай `docs/tasks/release/_RULES.md`, `docs/reference/R4_DATA.md`.

**Зачем.** Занести всё из паспорта в данные игры и в тексты ru/en.

## Шаги
Всё берётся **только из паспорта**. Если чего-то нет в паспорте — остановись и спроси.
1. `ZoneData`: id, цвета (пол, стена, небо, туман), границы, `base`, `luck_ref`, `mult`.
2. `GameConfig.XP_ZONE_MULT`: значение для биома.
3. `FoodData`: 3 вида (id, цвет, цена, `luck`, `aim_rank`).
4. `UpgradeData.BARS`: турник биома (цена, опыт).
5. `AnimalData`: 8 зверей (id, ранг 1–8, `base_income`, `size_m`). `base_income` бери по соседним биомам: у зверя ранга r доход пропорционален `base` биома по тому же правилу, что в биомах 1–5 (посмотри в данных соседнего биома и повтори отношение).
6. `MiniZoneData`: 6 имён.
7. `PetData`: питомец (зверь ранга 8).
8. `Loc` (ru, en, tr — если язык `tr` оставлен в T60): название биома, звери, еда, турник, мини-зоны, питомец. Ключи по образцу соседнего биома.
9. Массивы в `Save.DEFAULTS`, зависящие от числа биомов: расширь миграцией (старое сохранение должно загружаться, новые значения — по умолчанию).
10. Не включай биом в игру (`zones_open` не менять): без рецептов зверей он ещё неиграбелен.

## Проверка
`python tools/check_loc.py` без ошибок. `python tools/test.py`. Старое сохранение загружается (тест миграции).

## Тебе проверить
Открой файлы данных и сверь числа с паспортом.

**Готово, когда:** данные и тексты внесены, `check_loc.py` без ошибок.
