# B7 — Интерфейс

Запуск: `Выполни B7 для биома <id>`. Паспорт: `docs/biomes/NN_<id>.md`. Требуются B3–B6.
Прочитай `docs/tasks/release/_RULES.md`, `docs/tasks/T18.md`, `T40.md`, `docs/reference/R6_UI.md`.

## Шаги
1. Индекс: вкладка нового биома (иконка зоны, 8 зверей, награда Индекса, питомец). Вкладки прокручиваются (B0).
2. Шкала броска (`ThrowMeter`): сегмент нового биома, читаемость (не уже 8 пикселей при ширине 360).
3. Награда Индекса и питомец: выдаются за полный Индекс биома (T53), сумма награды — `mult` из паспорта.
4. Уведомления о новой еде и новом турнике появляются при входе в биом (как у других биомов).
5. Все кнопки не меньше 64×64; тексты влезают на ru и en (проверь длинные названия).

## Проверка
Все проверки; `check_loc.py`.

## Тебе проверить (на телефоне)
1. Вкладка Индекса, шкала, награда и питомец читаются.
2. Названия не обрезаются.

**Готово, когда:** всё читается на телефоне, минимальные размеры кнопок 64×64.
