# T68 — Вес и загрузка

Прочитай `docs/tasks/_RULES.md`, `CLAUDE.md`, `PROGRESS.md`, `docs/reference/R8_ASSETS.md`, `docs/reference/R7_YANDEX.md`.

**Зачем.** Игра в браузере: чем меньше архив, тем быстрее первый кадр, тем меньше игроков уходят.

## Шаги

### 1. Требования Яндекса
**СТОП: спроси владельца:** «Открой консоль Яндекс Игр → требования к игре. Какой максимальный размер архива и есть ли ограничение по размеру начальной загрузки? Пришли числа дословно». Не бери числа из памяти. Запиши их в `docs/reference/R7_YANDEX.md` с датой.

### 2. Сборка и размер
1. Запусти `python tools/build.py`. Найди итоговый архив (путь печатается в выводе).
2. Выведи размер в МБ (`ls -l` или `du -h`). Запиши в отчёт.
3. Разложи по составу: размер `.wasm`, `.pck`, звуков, текстур. Команда: `du -ah build | sort -rh | head -30`. Запиши топ-10 самых тяжёлых файлов.

### 3. Звуки
Найди все звуки: `find assets -name "*.wav" -o -name "*.mp3" -o -name "*.ogg"`. Звуки должны быть **OGG**. Если есть `.wav`/`.mp3` — конвертируй в `.ogg` командой `ffmpeg -i in.wav -c:a libvorbis -q:a 3 out.ogg` (если `ffmpeg` нет — выпиши список файлов в отчёт и `СТОП: спроси владельца`). После конвертации обнови ссылки в `scripts/` и `Audio`-данных (grep по старому имени) и удали старые файлы.

### 4. Текстуры
Найди крупные PNG: `find assets -name "*.png" -size +200k`. Для каждой крупной текстуры в настройках импорта Godot выставь сжатие «Lossy» (WebP) там, где качество не критично (иконки мелкие — оставь без потерь, если они меньше 64 КБ). Перед изменением выпиши список в отчёт. Прямой правки `.png` не делай, меняй только `.import`-настройки.

### 5. Повторная сборка
Снова `python tools/build.py`, размер до/после — в отчёт. Игра запускается из сборки (**Тебе проверить** ниже).

### 6. Время до первого кадра
**СТОП: спроси владельца:** «Открой собранную игру в Chrome, DevTools → Network → Throttling: Slow 4G (или Fast 3G), Disable cache. Сколько секунд до первого кадра игры?». Запиши число в отчёт. Если больше 10 с — предложи, что можно убрать из начальной загрузки (список файлов), но не удаляй без согласия.

## Проверка
Все проверки из `_RULES.md`. Звуки в игре играют (`python tools/test.py` не падает).

## Тебе проверить
1. Игра из новой сборки запускается и звуки на месте.
2. Визуально сравни иконки и текстуры до/после: нет заметных артефактов.

**Готово, когда:** размер архива записан и укладывается в требование консоли, звуки OGG, время до первого кадра записано.
