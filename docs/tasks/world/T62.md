# T62 — Ограничитель биомов и экран «Скоро»

Прочитай `docs/tasks/_RULES.md`, `CLAUDE.md`, `PROGRESS.md`, `docs/tasks/T24c.md`, `docs/tasks/T18.md`.

**Зачем.** Новые биомы будут выходить по одному. Игрок не должен видеть недоделанное, а мы должны открывать биомы одной настройкой в консоли Яндекса, без новой сборки.

## Правила
- Удалённый флаг называется `zones_open`: целое число — сколько биомов доступно. По умолчанию **5**.
- Значение всегда обрезается: не меньше 1 и не больше `ZoneData.count()`. Мусор (текст, пустое, дробное) → используется 5.
- Если флага нет (нет сети, нет SDK) — тоже 5.

## Шаги

### 1. Найди, что уже есть
- Инфраструктура флагов (T24c): `grep -rn "flag" scripts --include=*.gd`. Найди, как читаются `ad_interval_s`, `boost_s`, и скопируй их способ.
- `ThrowScale`: найди, как он узнаёт число зон.
- Где мир задаёт конец коридора: `grep -rn "CORRIDOR_LEN" scripts`.
- Где Индекс строит вкладки биомов.
- Где питомцы и награды проходят по списку зон.

### 2. Флаг
Добавь чтение `zones_open` рядом с остальными флагами, с обрезкой диапазона. Сохрани результат в одном месте, например `Game.zones_open()`.

### 3. `ThrowScale.open_zones`
Добавь свойство `ThrowScale.open_zones` = `Game.zones_open()`. Все места, где раньше стояло число зон, берут `open_zones`:
- шкала броска не предлагает зоны дальше открытых;
- звери из закрытых зон не выпадают;
- еда закрытых зон не продаётся.

### 4. Мир
Коридор оканчивается в конце последнего **открытого** биома. Дальше пройти нельзя (стена/барьер, как у существующего края мира). Закрытые биомы не строятся вообще (экономия мешей).

### 5. Табличка «Скоро новый биом»
В конце коридора поставь табличку с текстом «Скоро новый биом» (ru/en). Используй ту же технику, что у существующих табличек (T16). Табличка стоит **всегда**, пока открыто меньше запланированных биомов: добавь константу `GameConfig.PLANNED_ZONES := 20` и показывай табличку, если `open_zones < PLANNED_ZONES`. Так она есть и в демо из 5 биомов, когда остальных биомов в коде ещё нет.

### 6. Индекс
Вкладки закрытых биомов скрыты. После вкладки последнего открытого биома — недоступная вкладка-заглушка «Скоро» (серая, без содержимого), если `open_zones < PLANNED_ZONES`.

### 7. Тест
Headless-тест для `zones_open = 5`, `3`, `1`, `99` (→ обрежется), `"abc"` (→ 5):
- число построенных зон мира = обрезанное значение;
- длина коридора совпадает с концом последней открытой зоны;
- число вкладок Индекса = обрезанное значение (+1 заглушка, пока `open_zones < PLANNED_ZONES`);
- табличка стоит, пока `open_zones < PLANNED_ZONES`.
Пока в коде всего 5 биомов, значения 3 и 1 проверяют, что ограничитель работает при меньшем числе, а значение 99 обрезается до 5.

## Проверка
Все проверки из `_RULES.md` + новый тест.

## Тебе проверить
1. Через отладку поставь `zones_open = 3`: дальше конца третьего биома пройти нельзя, табличка стоит, в Индексе три вкладки и «Скоро».
2. Поставь 5: все 5 биомов видны, в конце пятого стоит табличка «Скоро новый биом», в Индексе после пятой вкладки заглушка «Скоро».

**Готово, когда:** при `zones_open = 5` дальше последнего биома пройти нельзя; изменение флага меняет число доступных биомов без новой сборки; мусорное значение игнорируется.
