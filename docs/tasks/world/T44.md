## Что сделать

### 1. Новый файл `scripts/logic/throw_scale.gd`

`class_name ThrowScale`, `extends RefCounted`, только `static func`, без состояния. Комментарии на русском.

Константы:

```gdscript
const OLD_MAX_WIDTH: float = 0.25   # старый сегмент не шире 25 % шкалы
const LAST_WEIGHT: float = 2.0      # последний сегмент вдвое «тяжелее» старого
const PERFECT_FROM: float = 0.95    # «Идеально!»: положение ползунка не меньше этого значения
const END_EPS: float = 0.01         # не доходить до границы зоны, иначе еда попадёт в следующую зону
```

Функции:

1. `segment_widths(n: int) -> Array[float]`  
   n это число открытых биомов (сегментов). Если n < 1, считать n = 1.  
   - n == 1: `[1.0]`.  
   - Иначе ширина старого сегмента `w = minf(1.0 / (float(n) + 1.0), OLD_MAX_WIDTH)`. Старых сегментов n−1 штук, каждый шириной w. Последний сегмент шириной `1.0 − (n−1) * w`.  
   - Сумма всегда 1.0 (допуск 1e-6).  
   Проверочные значения: n=2 → 0.25, 0.75. n=3 → 0.25, 0.25, 0.5. n=4 → 0.2, 0.2, 0.2, 0.4. n=10 → девять по 1/11 и последний 2/11.
2. `segment_starts(n: int) -> Array[float]`: левые границы сегментов (первый 0.0), размер n.
3. `segment_at(v: float, n: int) -> int`: номер сегмента для положения ползунка v. v обрезается в 0…1. Граница принадлежит правому сегменту (левая граница включена), v = 1.0 даёт последний сегмент. NaN даёт 0.
4. `open_zones(dmax: float) -> int`: `ZoneData.zone_at(dmax) + 1`.
5. `max_distance(strength: int) -> float`: `GameConfig.DIST_K * float(strength + GameConfig.BONUS_MAX)`.
6. `distance_at(v: float, n: int, dmax: float) -> float`: дальность броска.  
   - `i = segment_at(v, n)`, `t = (v − start_i) / width_i`, t обрезать в 0…1 (если width_i = 0, t = 0).  
   - Если `i < n − 1` (старый биом): `from = ZONES[i].start_m`, `to = ZONES[i].end_m − END_EPS`, результат `from + t * (to − from)`.  
   - Если `i == n − 1` (последний): `from = ZONES[i].start_m`, `to = maxf(dmax, from)`, результат `from + t * (to − from)`.  
   - Индекс зоны i обрезать в 0…`ZoneData.count() − 1`.
7. `is_perfect(v: float) -> bool`: `v >= PERFECT_FROM`.

Старые функции `ThrowCalc` не трогать и не удалять.

### 2. Новый файл `scripts/data/mini_zone_data.gd`

`class_name MiniZoneData`, `extends RefCounted`. Данные и простые формулы мини-зон.

```gdscript
const PER_ZONE: int = 6
# Множитель яркости пола по номеру мини-зоны 0…5 (чередование светлее/темнее, чтобы границы были заметны).
const SHADE: Array[float] = [1.00, 0.94, 1.06, 0.96, 1.08, 0.98]
```

Функции:

1. `name_key(zone: int, index: int) -> String`: ключ `"mini_" + ZoneData.ZONES[zone]["id"] + "_" + str(index + 1)`, например `mini_forest_1`. zone и index обрезать в допустимые пределы.
2. `index_at(dist: float) -> int`: номер мини-зоны 0…5 внутри зоны, где находится dist. `f = zone_fraction` (как в `SpawnRoller.zone_fraction`, но не вызывать её, чтобы логика не зависела от SpawnRoller; формулу написать заново): `f = clampf((dist − start_m) / (end_m − start_m), 0, 1)`, `index = mini(PER_ZONE − 1, int(f * PER_ZONE))`.
3. `global_index(dist: float) -> int`: `ZoneData.zone_at(dist) * PER_ZONE + index_at(dist)`.
4. `progress_in(dist: float) -> float`: доля пройденного внутри текущей мини-зоны, 0…1. Формула: `f * PER_ZONE − index` с обрезкой 0…1.
5. `start_m(zone: int, index: int) -> float` и `end_m(zone: int, index: int) -> float`: границы мини-зоны в метрах (длина зоны делится на 6 поровну).
6. `count() -> int`: `ZoneData.count() * PER_ZONE`.
