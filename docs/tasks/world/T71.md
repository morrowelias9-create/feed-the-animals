# T71 — Страница игры

Прочитай `docs/tasks/_RULES.md`, `CLAUDE.md`, `PROGRESS.md`, `docs/reference/R7_YANDEX.md`, `docs/reference/R10_MODERATION.md`, `docs/reference/R9_MONETIZATION.md`.

**Зачем.** Страница игры в каталоге — витрина. Нужны тексты, картинки и честная возрастная категория. Агент готовит тексты и список, картинки делает владелец.

## Шаги

### 1. Требования консоли
**СТОП: спроси владельца:** «Открой консоль → страница игры. Пришли дословно: размеры иконки и обложки, число и размер скриншотов, максимальную длину названия и описания, список обязательных полей. И какие текущие требования модерации ты видишь?». Запиши в `docs/store/REQUIREMENTS.md` с датой. Не используй числа из памяти.

### 2. Тексты
Создай `docs/store/STORE_PAGE.md` с черновиками на ru и en, в пределах лимитов из шага 1:
- название игры (ru и en);
- короткое описание (1–2 предложения);
- полное описание: что делать (бросай еду, кормишь зверей, тренируйся, расширяй загон), что нового в биомах (5 биомов, 40 зверей), «заходи в гости к другим игрокам», «играй с телефона»;
- что нового в версии.
Пиши простым языком без преувеличений («лучшая в мире» нельзя). Не обещай того, чего нет в игре (новые биомы — только «скоро»).

### 3. Список скриншотов
Составь в `STORE_PAGE.md` список из нужного числа скриншотов (по шагу 1) с описанием кадра для каждого. Ориентир: (1) бросок с шкалой, (2) зверь после получения, (3) загон со зверями, (4) окно «Индекс», (5) один из дальних биомов (Океан), (6) турник. Для каждого — **как получить кадр**: какой режим отладки включить, где встать, на каком языке. Картинки делает владелец.

### 4. Фактические данные для возрастной категории
Составь в `STORE_PAGE.md` блок «Факты об игре» — без решения о категории, только факты:
- есть реклама (межстраничная и вознаграждаемая);
- есть покупки за яны (9 товаров);
- есть асинхронный мультиплеер: игрок видит загоны других (снимки); чата и сообщений **нет** (проверь `grep -rn "chat\|message" scripts` и подтверди);
- нет насилия, нет азартных механик на деньги? (**проверь:** «Счастливые броски» и мутации — это платная вероятность; напиши об этом честно в фактах);
- сохранение через аккаунт Яндекса.
**СТОП: спроси владельца** категорию: «Какую возрастную категорию выбрать? Консоль определит по анкете — заполни анкету по этим фактам».

### 5. Соответствие модерации
Пройди по `R10_MODERATION.md` и `REQUIREMENTS.md` и для каждого пункта пиши ✅/❌/«не знаю». Все ❌ — в отчёт.

## Проверка
Файлы `docs/store/REQUIREMENTS.md` и `docs/store/STORE_PAGE.md` заполнены, тексты ru и en в лимитах.

## Тебе проверить
1. Прочитай тексты. Исправь названия и обещания.
2. Сделай скриншоты по списку, загрузи в консоль.

**Готово, когда:** тексты, скриншоты, иконка и обложка загружены в консоль, анкета возрастной категории заполнена.
