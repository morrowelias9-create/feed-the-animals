# T49. Эпоха II: данные зон и зверей

**Статус: черновик.** Перед началом агент задаёт пользователю вопросы из раздела «Вопросы до начала» и ждёт ответов. Пока ответов нет, задачу не выполнять.

**Зависит от:** T44, T45, T46, T47, T48.  
**Читать:** `R3_BALANCE.md`, `R4_DATA.md` (зверь, ранги), `R5_SAVE.md`. Файлы: `scripts/data/zone_data.gd`, `scripts/data/animal_data.gd`, `scripts/logic/economy.gd`, `scripts/logic/spawn_roller.gd`, `scripts/ui/index_window.gd` (только цикл по `ZoneData.count()`), `autoload/game.gd` (строки с `ZoneData.count()`), `scripts/util/num_fmt.gd`.

## Цель

Добавить в данные ещё 5 зон: те же биомы, но «Эпоха II», и 40 зверей этой эпохи, чтобы бросок мог попасть дальше 2100 м. Мир и внешний вид в этом шаге не меняются (T50).

## Предлагаемое решение (подтвердить пользователем)

1. Зон становится 10. Зоны 5–9 это копии зон 0–4 со сдвигом: `id` получает суффикс `_2` (`forest_2`, …), `start_m` и `end_m` увеличиваются на 2100, `name_key` тот же с суффиксом `_2` (новые ключи, например «Лес древности»), `base = 40^g` где g это номер зоны (получается 1,024e8 для зоны 5), `mult` растёт ×15 на зону, цвета `ground`, `sky`, `fog`, `wall` уточняются в T50 (пока копии).
2. Звери эпохи II: для каждого из 40 зверей создаётся запись с `id = <id>_e2`, тем же видом и рангом, зоной `зона + 5`, `base_income` по формуле зоны. Имя через новый ключ `animal_<id>_e2` (ru «Древний {имя}»). Модель, иконка, высота: берутся от базового `id` (в `ModelLoader`, `AnimalView`, `index_window` для `_e2` использовать базовый `id`, если своих файлов нет). Эпохальный декор на модели делается в T50.
3. Все системы, где ключом служит `animal_id`, продолжают работать: сохранения (`animals`, `found`) получают просто новые строковые id.
4. `luck_ref` зон 5–9 подобрать так, чтобы коэффициент удачи `lm` в середине зоны при лучшей еде зоны (T51) был около 1,0…1,4 (как в эпохе I). Подбор по `tools/sim_progress.py` (расширить модель на 10 зон).
5. `SpawnRoller.zone_at` и `rank_cap` работают без изменений (зоны обрабатываются по таблице).

## Вопросы до начала (задать пользователю)

1. Подходит ли схема «те же звери с пометкой эпохи, id `<id>_e2`, имя «Древний …»», или в эпохе II нужны другие звери? Если другие, сколько и какие?
2. Доход зверя эпохи II: ×40 на каждый следующий биом (`base = 40^g`), то есть Лес эпохи II в 1,024e8 раза доходнее Леса эпохи I. Подходит?
3. Нужен ли отдельный потолок силы или переход эпохи II открывается просто дальностью (дальше 2100 м)? Предлагаю просто дальностью.

## Что сделать (после ответов)
