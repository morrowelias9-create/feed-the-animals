# T55 — `PROGRESS.md` по факту

Прочитай `docs/tasks/_RULES.md`, `CLAUDE.md`, `PROGRESS.md`.

**Зачем.** Отметки «сделано/зафиксировано» в `PROGRESS.md` расходятся с историей git. Агенты верят `PROGRESS.md`, поэтому в нём должна быть правда.

**Трогаем только** `PROGRESS.md`. Код не трогаем.

## Шаги

### 1. Собери факты из git
1. Выполни `git log --oneline --no-decorate > /tmp/log.txt` и `wc -l /tmp/log.txt`.
2. Для каждой задачи в `PROGRESS.md` найди коммиты: `git log --oneline --grep="Txx"` (подставь номер, например `T16`). Запомни, есть ли хотя бы один коммит.

### 2. Составь таблицу расхождений
Для каждой задачи, у которой в `PROGRESS.md` стоит «зафиксировано» (или похожее), а коммитов с её номером **нет**, выпиши строку: `Txx — в журнале «зафиксировано», коммитов нет`. Обязательно проверь: T16, T19, T24c, T24e, T24e-1…T24e-4, T21, T25, T28, T29.
Особые случаи:
- T24c записана дважды. Найди оба блока, сравни. Оставь тот, где больше деталей. Если детали разные — объедини в один блок, ничего не теряя.
- T24e: у подзадач T24e-1…T24e-4 коммиты `T24e: звери Саванны`, `...Пустыни`, `...Джунглей`, `...Океана`. Если все 4 коммита есть — T24e закрыта.
- T21, T25, T28, T29: не закрыты. Оставь незакрытыми.

### 3. СТОП: спроси владельца
Покажи таблицу расхождений. Спроси: «Для этих задач поставить статус «сделано, не зафиксировано» вместо «зафиксировано»? (да / нет / список исключений)». Жди ответа.

### 4. Исправь `PROGRESS.md`
- Для подтверждённых строк замени статус на «сделано, не зафиксировано (коммита нет)».
- Удали дубль T24c.
- Закрой T24e (если выполнено условие шага 2).
- Формат записей не меняй: копируй стиль соседних строк.

### 5. Добавь чеклист этого плана
В конец раздела с чеклистом добавь строки, по образцу существующих, со статусом ⬜ (не сделано):
T54, T55, T56, T57, T58, T59, T60, T61, T62, T63, T64, T65, T66, T67, T68, T69, T70, T71, T72, B0.
Названия бери из `docs/PLAN_RELEASE.md`. Добавь пометку: «T28 заменён T67, T29 заменён T70–T72».

## Проверка
- Для каждой задачи, помеченной «зафиксировано», `git log --grep` находит коммит.
- В файле ровно один блок T24c.

## Тебе проверить
1. Просмотри `git diff PROGRESS.md`: нет ли потерянных записей.

**Готово, когда:** `git log` и отметки в `PROGRESS.md` совпадают.
