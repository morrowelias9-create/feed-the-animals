**T24b. Соседи: асинхронный мультиплеер**
Зависит от: T24a. Сначала найди актуальную документацию `ysdk.multiplayer.sessions`.
- Задача: `Ya.mp_init(count, meta)`, `Ya.mp_commit(payload)`, `Ya.mp_push(meta)`, событие транзакций. Запись: раз в 20 с снимок `{t:"pen", a:[[id,variant,size],...до 10]}`, при каждом броске `{t:"throw", d:метры, f:еда}`. `push` с `meta1 = strength`, `meta2 = zone_max` после 3 минут игры и при уходе в фон (уточни по документации, когда безопасно). Загрузка: 4 сессии с силой ±30%. `neighbor_view.gd` на соседних участках: имя игрока над участком (пустое имя показывать как «Игрок»), его звери из снимка гуляют, его человечек бросает еду в момент события `throw`, еда летит по коридору (без кинематики). Нет сессий: на участке табличка «Свободный участок», выдуманных игроков нет. Размер записи меньше 200 КБ.
- Тебе проверить: на черновике с двух аккаунтов: второй видит первого соседом.
