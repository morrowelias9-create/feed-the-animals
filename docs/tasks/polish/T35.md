# T35. Высота камеры по размеру зверя

**Зависит от:** T10c, T11a.  
**Читать:** `R2_GAMEPLAY.md` (кинематика получения), `R4_DATA.md` (размеры животных), `R8_ASSETS.md` (нормализация моделей).

## Проблема

Высота/цель камеры не учитывает реальный размер животного: маленький заяц должен смотреть на еду почти с уровня земли, а слон — заметно сверху.

## Что сделать

1. Найти источник фактической высоты модели после нормализации и использовать его для расчёта камеры.
2. Высоту точки обзора и положение камеры вычислять относительно размеров конкретного экземпляра, включая модификатор роста.
3. Для маленьких животных устанавливать низкую точку обзора; для крупных — более высокую.
4. Ограничить значения разумным минимумом и максимумом, чтобы камера не уходила под землю и не улетала слишком высоко.
5. Сохранить направление взгляда на еду и плавность движения камеры.
6. Проверить крайние размеры, включая мутацию роста x4.

## Критерии готовности

- Камера заметно различается для маленьких и крупных зверей.
- Высота соответствует фактической модели, а не только базовому ID.
- Нет резких скачков при старте/переходах катсцены.

**Тебе проверить:** сравнить катсцены зайца, обычного крупного зверя и зверя с ростом x4.
