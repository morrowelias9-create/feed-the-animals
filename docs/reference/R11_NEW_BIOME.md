# R11 — Новый биом: правила и формулы

Справочник для шагов B0–B10 (`docs/tasks/release/biome/`). Все числа выведены из пяти существующих биомов. Если ты считаешь новый биом, бери числа отсюда, затем подгоняй симулятором (`python tools/sim_progress.py`).

## Правила после релиза демо
- Данные биомов 1–5 **не менять**.
- Поля `Save.DEFAULTS` не удалять и не переименовывать без миграции.
- Массивы в сохранении расширять **только** миграцией (дополнять значениями по умолчанию).
- Подстройку баланса после релиза делать только удалёнными флагами.

## Формулы чисел биома
| Что | Правило |
|---|---|
| Длина биома | от 300 до 600 м; начало = конец предыдущего |
| `base` | `base` предыдущего биома × 40 (шаг может измениться после решения B0 п.2) |
| `mult` (награда Индекса) | `mult` предыдущего × примерно 15 |
| `luck_ref` | середина биома (в метрах) × `luck` второй еды биома |
| Еда | 3 вида, `aim_rank` 2 / 5 / 8; цена предыдущей еды × примерно 4,6; `luck` + примерно 0,143 к предыдущей |
| Турник | минимум 1 на биом; опыт ×2 к предыдущему; цена предыдущего × от 7 до 8 |
| `XP_ZONE_MULT` | подбирается симуляцией |

## Цели по времени
- Время биома: 1,5–2 активных часа.
- Первая еда биома куплена в окне «вход в биом + 2 минуты … вход + треть биома».

## Состав биома
- 8 зверей, ранги 1–8 без пропусков;
- 3 вида еды;
- 1 турник (минимум);
- 6 мини-зон (имена);
- 1 питомец (зверь ранга 8);
- декор, небо, туман, цвет пола и стен.

## Файлы, которые трогает новый биом
`ZoneData`, `GameConfig.XP_ZONE_MULT`, `FoodData`, `UpgradeData.BARS`, `AnimalData`, `MiniZoneData`, `PetData`, `Loc`, `scripts/data/recipes/<id>.gd`, `food_recipes.gd`, `LookData.BAR_LOOKS`, `BarModel`, `WorldBuilder`, `SceneryBuilder`, `ZoneLook`, иконки `assets/ui/icons/animal_<id>.png`, `food_<id>.png`, `zone_<id>.png`, текстура `ground_<id>`.
