# R3. Формулы и баланс

## Редакция 3 — актуальные формулы (ноябрь 2026)
Источник: код в `scripts/data/` и `scripts/logic/`. Симулятор: `tools/sim_progress.py` (читает дамп из `tools/data_dump.json`).

### Бросок и дальность
- **Ползунок**: `v` ∈ [0, 1]. `bonus = round(20 * v)` ∈ [0, 20]. `bonus ≥ 19` — «Идеально!».
- **Эффективная сила**: `eff = strength + bonus`.
- **Дальность**: `dist = DIST_K * eff`, `DIST_K = 4.0` м/ед.
- **Зона**: последняя зона с `start_m ≤ dist`. Границы биомов:
  - Лес: 0–180 м
  - Саванна: 180–480 м
  - Пустыня: 480–1050 м
  - Джунгли: 1050–1650 м
  - Океан: 1650–2100 м
  - `CORRIDOR_LEN = 2100` м

### Выбор зверя (SpawnRoller, RollData)
- **Доля по биому**: `f = clamp((dist - start_m) / (end_m - start_m), 0, 1)`.
- **Центр колокола рангов** плавно растёт по биому, зависит от еды (`aim_rank`):
  - Еда своей зоны: `center = CENTER_START + CENTER_START_SLOPE*(aim-5) + (CENTER_END + CENTER_END_SLOPE*(aim-5) - ...) * f`
  - Еда прошлой зоны: центр между `OLD_FOOD_CENTER_START=1.4` и `OLD_FOOD_CENTER_END=2.4`
  - Константы: `SIGMA=1.5`, `CENTER_START=2.55`, `CENTER_START_SLOPE=0.10`, `CENTER_END=4.15`, `CENTER_END_SLOPE=0.10`
- **Вес ранга**: `w(r) = exp(-(r - center)² / (2 * SIGMA²))` для `r=1..8`. Потолка по третям нет — все 8 рангов доступны.
- **Анти-повтор**: вес последнего пойманного зверя / 50, предпоследнего / 2.5.
- **Страховка (pity)**: серия без ранг 4+ → вес рангов 4+ × (1 + 0.12 × серия); серия без ранг 6+ → вес рангов 6+ × (1 + 0.03 × серия).
- **Джекпот**: каждые 25–35 бросков (случайный порог) гарантированно выдаются два соседних ранга (нижний растёт по биому от 4 до 7, верхний вдвое реже). Джекпот сбрасывает серии страховки.
- **Новые виды**: зверь, которого нет в Индексе, выпадает в 2.5 раза чаще.
- **Шкала «До джекпота»**: не показывается игроку (`SHOW_JACKPOT_METER = false`).

### Удача (SCORE) и множитель шансов
- `luck = round(dist * food.luck * (1.25 если «Идеально!», иначе 1))`
- `lm = clamp(luck / zone.luck_ref, LM_RAW_MIN, LM_RAW_MAX)` → `LM_MIN + (LM_MAX - LM_MIN) * (lm - LM_RAW_MIN) / (LM_RAW_MAX - LM_RAW_MIN)`
- Константы: `LM_RAW_MIN=0.6`, `LM_RAW_MAX=2.0`, `LM_MIN=0.85`, `LM_MAX=1.35`
- `luck_ref` по зонам: [105, 525, 1500, 3300, 5400]

### Мутации (VariantData)
- 5 мутаций + обычный. Базовые шансы при `lm=1`: золото 9%, бриллиант 3.5%, изумруд 1.5%, рубин 0.7%, радуга 0.3%. Сумма = 15%.
- Шансы умножаются на `lm`; если сумма > 35% — пропорционально ужимаются.
- Множители дохода: 1.5 / 3 / 5 / 10 / 20.

### Размер (SizeData)
- `p = SIZE_P0 * lm` (`SIZE_P0 = 0.18`). Пока `randf() < p` и `k < SIZE_MAX (20)`: `k += 1`, `p = min(p + 0.05, 0.4)`.
- Доход: × `SIZE_STEP^(SIZE_POW * k)` (`SIZE_STEP=1.5`, `SIZE_POW=1.8`).
- Визуальный масштаб: `min(1 + 0.22 * k, 2.6)`.

### Доход зверя
`income = zone_base * RANK_STEP^(rank-1) * variant_mult * size_mult`
- `RANK_STEP = 1.5`
- `zone_base`: [1, 40, 1600, 64000, 2_560_000]

### Продажа, загон, рюкзак
- Продажа: `income * SELL_MULT` (`SELL_MULT = 30`).
- Загон: старт 4 слота, +2 за уровень (8 уровней), цены в `UpgradeData.SLOT_PRICES`. Макс. 20 слотов.
- Рюкзак: до 60 зверей (стоящие + не стоящие). При переполнении худший продаётся автоматически.

### Сила и опыт (Economy, GameConfig)
- Опыт за повторение: `BAR_XP[bar_tier]` (1, 2, 4, 8, 16, 32, 64, 128, 256, 512). Первый турник стоит 1.
- `xp_needed(S) = 30 * XP_ZONE_MULT[zone_of(4*S)] * (1 + S/40)`
- `XP_ZONE_MULT` по зонам: [3.3, 3.4, 5.9, 13.7, 28.1]
- Зона силы определяется по `dist = 4 * S` (как при броске).

### Оффлайн-доход
- `OFFLINE_RATE = 0.1` (10%), `OFFLINE_CAP_S = 3600` (1 час), `OFFLINE_MIN_S = 60`.
- Формула: `min(прошло, 3600) * доход_размещённых * 0.1`.

### Буст (rewarded)
- `BOOST_MULT = 2`, `BOOST_S = 300` (5 мин), `BOOST_MAX_S = 1800` (30 мин вперёд).

### Индекс и награды
- Награда за полную зону: `INDEX_REWARD_BASE * zone.mult` (`INDEX_REWARD_BASE = 5000`).
- Питомцы за полный Индекс биома: +5% доход (Лес), +10% удача/опыт/продажа (остальные).

### Ориентиры темпа (симулятор `sim_progress.py`, активная игра 3 с тренировки/мин, бросок раз в 6 с)
- Вход в Саванну: ~0.54 ч
- Вход в Пустыню: ~1.35 ч
- Вход в Джунгли: ~2.47 ч
- Вход в Океан: ~3.87 ч
- Конец Океана (мини-зона 5.6): ~5.87 ч
