# R3. Формулы и баланс

## Редакция 3 — новые формулы
Источник: PLAN_original.md, строка 167.

### R3, редакция 3: формулы [наше по мотивам гайда, числа свои, настраиваются симуляцией]
- **Дальность**: `dist = DIST_K * (strength + bonus)`, `DIST_K` = 4, бонус шкалы 0-20.
- **Треть зоны**: `f = (dist - start_m) / (end_m - start_m)`; `f < 1/3` потолок ранга 4, `f < 2/3` потолок 6, иначе 8.
- **Ранг**: вес `w(r) = exp(-(r - aim)^2 / (2 * 1.4^2))` для `r <= потолок`; `aim` = `aim_rank` еды, если еда этой зоны; если еда из прошлой зоны, `aim = 1`; если из будущей, `aim = 8`. Анти-повтор: вес последнего пойманного зверя / 50, предпоследнего / 2.5. В зоне 8 зверей, ранг = зверь.
- **Удача (SCORE)**: `luck = round(dist * food.luck * (1.25 если «Идеально!», иначе 1))`. Множитель шансов `lm = clamp(luck / zone.luck_ref, 0.6, 2.0)`, `zone.luck_ref` в `ZoneData`.
- **Мутация**: один `randf()`, шансы R4, умноженные на `lm` (сумма не выше 35%).
- **Размер**: `p = SIZE_P0 * lm` (`SIZE_P0` = 0.18); пока `randf() < p` и `k < SIZE_MAX` (10): `k += 1`, `p = min(p + 0.05, 0.4)`. Доход x`SIZE_STEP^(SIZE_POW * k)`, `SIZE_STEP` = 1.5, `SIZE_POW` = 1.8. Визуальный масштаб `min(1 + 0.22 * k, 2.6)`.
- **Доход**: `zone_base * RANK_STEP^(rank-1) * variant_mult * size_mult`, `RANK_STEP` = 1.5, `zone_base` = 1, 40, 1600, 64000, 2 560 000.
- **Продажа**: доход x30. **Загон**: вместимость 4, 6, 8, 10, 12, 14, 16, 18, 20; цены в `UpgradeData` (симуляция). **Рюкзак**: до 60 зверей вместе с загоном.
- **Сила**: `xp_needed(S) = 30 * XP_ZONE_K^(zone_of(4*S)) * (1 + S/40)`, `XP_ZONE_K` = 3.5; каждый турник x2 опыта.
- **Ориентиры темпа**: первый турник и яблоко за 1-2 мин, Саванна 8-12 мин, Пустыня 35-50 мин, Джунгли 2-3 ч, Океан 6-9 ч.

## Базовая редакция — историческая, возможны конфликты
Источник: PLAN_original.md, строка 390.

### R3. Формулы и числа

Числа в `GameConfig`: `DIST_K=4.0`, `BONUS_MAX=20`, `SELL_MULT=30`, `INV_LIMIT=60`, `OFFLINE_CAP_S=7200`, `OFFLINE_RATE=0.5`, `OFFLINE_MIN_S=60`, `BOOST_S=300`, `BOOST_MAX_S=1800`, `BOOST_MULT=2`, `AUTOSAVE_S=15`, `INDEX_REWARD_BASE=5000`, `NEED_A=10`, `NEED_B=4`, `NEED_C=60`, `TIER_LUCK=0.25`, `BAR_REP_INTERVAL=0.25`, `FX_ENABLED=true`, `REVEAL_EYES_S=1.6`, `REVEAL_SIDE_S=1.2`, `REVEAL_LETTER_S=0.12`, `REVEAL_AUTO_S=8.0`, `RARITY_INCOME=[1,3,10,40,200]`, `BASE_W=[70,20,7,2.5,0.5]`, `SIZE_BY_RARITY=[1.2,2.2,3.5,5.0,7.0]`.

Эти числа стартовые [наше], проверены грубой симуляцией `python tools/sim_economy.py`. Меняешь число в игре, меняй и в симуляторе.

- **Бросок** [скриншот 4: шкала и «+11»; формулы наши]. Ползунок `v` от 0 (низ) до 1 (верх). `bonus = round(20 * v)` [гайд: бонус до +20 у верха шкалы]. `eff = strength + bonus`, `strength` целое, старт 1. `dist = 4 * eff` м. `bonus >= 19` называется «Идеально!». Зона: последняя из `ZONES`, у которой `start_m <= dist`.
- **Какой зверь**: зона по дальности; редкость `r` (0-4) по весам `BASE_W[r] * (1 + 0.25 * tier)^r`, `tier` это выбранная еда 0-9; зверь из зоны и редкости равновероятно; вариант по `VariantData` (R4): бриллиантовый 1%, золотой 3%, иначе обычный. Для справки: доля легендарного 0.5% на тире 0, 3.2% на тире 3, 11.1% на тире 7, около 16% на тире 9.
- **Доход**: `income = mult_зоны * RARITY_INCOME[r] * VariantData.mult(variant)`. Доход идёт только от зверей в загонах, начисляется каждый кадр по `delta`.
- **Продажа**: `income * 30`. Лимит инвентаря 60 (все звери, стоящие и нет); при переполнении новый зверь продаётся автоматически с сообщением.
- **Сила**: одно повторение даёт `BAR_XP[bar_tier]` опыта. Для силы `S` следующий уровень требует `10 + 4 * S * (1 + S / 60)` опыта, лишнее переносится.
- **Участок**: старт 4 слота, расширение +2, шесть расширений за 600, 8 000, 100 000, 1 200 000, 15 000 000, 200 000 000, максимум 16. Табличка показывает «текущее > новое» и цену [скриншот 1].
- **Оффлайн**: `min(прошло, 7200 с) * доход_размещённых * 0.5`, окно при входе, если прошло больше 60 с.
- **Буст**: rewarded «x2 доход на 5 минут». `boost_until = max(now, boost_until) + 300`, не больше `now + 1800`.
- **Индекс**: зверь заносится при первом получении (вариант отдельно не учитывается). Награда за полную зону: `5000 * mult_зоны` денег один раз.
- **Ориентиры темпа** (симуляция, «разумный игрок», цель настройки, не гарантия): яблоко около 1 мин, первое расширение около 2 мин, Саванна около 7 мин, Пустыня 25-30 мин, Джунгли 2-3 ч, Океан 9-10 ч.


**Важно:** не смешивать числовые значения двух редакций автоматически. Если активный шаг не уточняет, какая редакция применима, остановиться и запросить решение пользователя. Список выявленных расхождений — `OPEN_QUESTIONS.md`.
